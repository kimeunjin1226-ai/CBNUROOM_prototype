# CBNU ROOM 프로토타입

충북대학교 양진재 기숙사생을 위한 생활·금융 플랫폼 앱 프로토타입입니다.
(금융상품 및 서비스 기획 팀 프로젝트)

- `index.html`: 아이폰 프레임 화면 (안에서 `app.html`을 띄워요)
- `app.html`: 실제 클릭형 프로토타입 (Claude 디자인 캔버스에서 내보낸 파일)
- 바로 보기: https://kimeunjin1226-ai.github.io/CBNUROOM_prototype/
- 금액, 계좌번호, 이름, 게시글 등 화면 속 데이터는 모두 프로토타입용 예시입니다.

## 주요 기능
로그인 → 계좌 연결·충전 → 결제 비밀번호 → 닉네임 설정, 개신페이(충전·송금·이용 내역), 세탁실(결제·찜하기),
공동구매·중고거래(안심결제·채팅), 정산·모임통장, 하자보수, 모바일 학생증, 커뮤니티, 냉난방비, 식사비 환급
